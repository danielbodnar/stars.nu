## Main commands

| Command | Description |
|---------|-------------|
| [`stars [query]`](/commands/stars/) | Display starred repos with optional search |
| [`stars version`](/commands/stars/#version) | Show version information |
| [`stars help`](/commands/stars/#help) | Show detailed help |

## Sync commands

| Command | Description |
|---------|-------------|
| [`stars sync`](/commands/sync/) | Sync from all configured sources (incremental) |
| [`stars sync github`](/commands/sync/#stars-sync-github) | Sync specifically from GitHub |

## Config commands

| Command | Description |
|---------|-------------|
| [`stars config`](/commands/config/) | Show current configuration |
| [`stars config init`](/commands/config/#init) | Initialize config file with defaults |
| [`stars config show`](/commands/config/#show) | Show current configuration (alias) |
| [`stars config get <key>`](/commands/config/#get) | Get a config value (dot notation) |
| [`stars config set <key> <value>`](/commands/config/#set) | Set a config value |
| [`stars config reset`](/commands/config/#reset) | Reset to defaults |
| [`stars config edit`](/commands/config/#edit) | Open config in `$EDITOR` |
| [`stars config path`](/commands/config/#path) | Show config file path |
| [`stars config validate`](/commands/config/#validate) | Validate configuration |

## Export commands

| Command | Description |
|---------|-------------|
| [`stars export csv`](/commands/export/#csv) | Export to CSV |
| [`stars export json`](/commands/export/#json) | Export to JSON |
| [`stars export nuon`](/commands/export/#nuon) | Export to NUON |
| [`stars export md`](/commands/export/#markdown) | Export to Markdown table |
| [`stars export firefox`](/commands/export/#firefox-bookmarks) | Export to Firefox bookmarks HTML |
| [`stars export chrome`](/commands/export/#chrome-bookmarks) | Export to Chrome bookmarks HTML |

## Analytics commands

| Command | Description |
|---------|-------------|
| [`stars stats`](/commands/stats/) | Show statistics about starred repos |
